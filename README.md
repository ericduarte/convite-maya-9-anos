# Convite da Maya — 9 anos 🌸🚲

Convite virtual interativo (HTML, CSS e JavaScript puros), publicado no GitHub Pages.

## Onde editar

| O quê | Onde |
|---|---|
| Data, horário, endereço | `index.html` (procure por ✏️) |
| Data do contador | `EVENT_DATE` em `script.js` |
| Link da planilha de confirmações | `SHEETS_URL` em `script.js` (veja `apps-script.gs`) |
| Música | coloque `musica.mp3` na raiz |
| Imagens | `img/` |
